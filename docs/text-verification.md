# Text verification

The Turkish `info`/`story` texts in `posts.yaml` were written by hand from the source records (Commons description,
institution record) and web sources, not generated by the caption pipeline. Where a fact is not in the record it is
either widely documented background or was checked against a second source:

| Post | Facts beyond the record | Checked against |
|---|---|---|
| muybridge-1878 | Stanford hired him in 1872; 19 June 1878, Palo Alto, twelve string-triggered cameras | Commons/LoC description |
| chinatown-genthe | Genthe used a small, discreet camera; came to San Francisco 1895 | web search (MoMA, LoC Genthe collection, Wikipedia) |
| klondike-1898 | one year of supplies required by the Canadian side | general historical knowledge |
| makinist-1920, newsies-1910 | Hine worked for the National Child Labor Committee | general historical knowledge |
| istanbul-selamlik | the photo was bought in Constantinople from the Sébah & Joaillier studio, not taken by the Hallwyl party | Commons record (Hallwyl Museum) |

Dates come from the source record and are quoted as such ("dated", "kayıtta"). Run `histposts caption <file>` (needs
`ANTHROPIC_API_KEY`) for an automated claim check on new posts.

## Automated check without an API key

`histposts facts facts.yaml` checks the claims that go beyond each photo's own record against Wikipedia through the
free MediaWiki API (no account, no key). For every claim it fetches the named article and requires that all listed
tokens (dates, numbers, names) appear in it. Result: [docs/fact-check.md](fact-check.md). The check found two real
problems, which were fixed: the exact Muybridge date (Wikipedia says June 1878, the card itself says 19 June 1878, so
the text now says both) and the mechanism that triggered the cameras (the text no longer names one). A pass means
"consistent with Wikipedia", not proof, and it does not judge wording.
